Data files

ReadWrite reads and writes matrix datasets in binary formats, and reads planar and higher-dimensional curves from text files (read_plt, the inverse of write_plt, and read_geolife_plt for GeoLife trajectories). Use import BasicCompGeometry as CG and qualified calls such as CG.ReadWrite.read_fbin(path), or import the namespace through Extras.

BasicCompGeometry.ReadWrite — Module
ReadWrite

A module for reading and writing various binary vector formats common in computational geometry and similarity search. Supports .fbin, .ibin, and .fvecs formats, and text files of planar curves (plain coordinate lists and GeoLife .plt trajectories).

BasicCompGeometry.ReadWrite.read_fbin — Function
read_fbin(filename::String, start_idx::Int = 0, chunk_size::Union{Int,Nothing} = nothing)

Read an .fbin file containing Float32 vectors. The format starts with two Int32 values: number of vectors and their dimension.

Arguments

  • filename: path to .fbin file.
  • start_idx: start reading vectors from this index (0-based).
  • chunk_size: number of vectors to read. If nothing, reads until the end.

BasicCompGeometry.ReadWrite.read_fvecs — Method
read_fvecs(filename::String)

Reads a binary .fvec file and returns a matrix where each column is a vector. The .fvec format consists of a 4-byte integer for the number of dimensions, followed by the single-precision floating-point vector data. This pattern repeats for each vector in the file.

source
BasicCompGeometry.ReadWrite.read_geolife_plt — Method
read_geolife_plt(filename)

Read a GeoLife .plt trajectory: six header lines, then comma separated records whose first two fields are the coordinates. Blank lines are skipped and consecutive repeated points are dropped.

BasicCompGeometry.ReadWrite.read_ibin — Function
read_ibin(filename::String, start_idx::Int = 0, chunk_size::Union{Int,Nothing} = nothing)

Read an .ibin file containing Int32 vectors. The format starts with two Int32 values: number of vectors and their dimension.

Returns a matrix where each row is a vector (consistent with original implementation).

source
BasicCompGeometry.ReadWrite.read_plt — Method
read_plt(filename; dim = 2)

Read a point sequence from a text file with one point per line, as written by write_plt: coordinates separated by commas and/or whitespace. The first dim numbers of each line are used. Blank lines, lines starting with #, and the header x y k tid (used by some datasets) are skipped, and consecutive repeated points are dropped.

write_fbin(filename::String, vecs::Matrix{Float32})

Write a matrix of Float32 vectors to an .fbin file. vecs is expected to have vectors as rows (to match read_fbin's metadata logic).
