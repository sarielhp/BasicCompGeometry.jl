BasicCompGeometry.BBT — Module
BBT

Bounding-box trees: a lazily built hierarchy of axis-aligned boxes over a point set, split at the midpoint of the widest dimension. Used for nearest-neighbor queries and as the substrate of the WSPD and MVBB modules. Points are reordered through a VArray, so orig_index recovers a point's index in the input. Start with Tree_init.

source
BasicCompGeometry.BBT.FlatNode2D — Type
FlatNode2D{T}

A compact node in a flat array-backed 2D FlatTree2D (Kd_tree.FlatTree2D).

Fields are ordered so FlatNode2D{Float64} packs cleanly into 64 bytes (one cache line). left, right, and parent are Int32 node indices (0 denotes none).

source
BasicCompGeometry.BBT.FlatTree2D — Type
FlatTree2D{T}

A flat array-backed 2D Bounding Box Tree / Kd-tree storing points in Structure-of-Arrays (px, py) layout alongside a permutation perm mapping leaf slots back to caller-supplied integer identifiers, plus reverse lookup arrays (leaf_of, slot_of).

Parent navigation uses index-based parent(ft, id), parent_node (parent_node(ft, id)), and is_root (is_root(ft, id)), where 0 denotes no parent.

source
BasicCompGeometry.BBT.FlatUNode2D — Type
FlatUNode2D{T}

A node in an unshrunk-cell flat 2D Kd-tree (FlatUTree2D, Kd_tree.FlatUTree2D), storing both the tight point bounding box (x0, x1, y0, y1) and the unshrunk split cell (ux0, ux1, uy0, uy1) alongside bound_mask::UInt8 (bits 0..3 mark constrained ux0, ux1, uy0, uy1 split walls).

FlatUNode2D{Float64} occupies 96 bytes.

source
BasicCompGeometry.BBT.FlatUTree2D — Type
FlatUTree2D{T}

A flat array-backed 2D Bounding Box Tree / Kd-tree using FlatUNode2D nodes that maintain both tight point bounding boxes and unshrunk split-cell rectangles (ux0, ux1] x (uy0, uy1] for faster bottom-up subtree stopping.

Parent navigation uses index-based parent(ft, id), parent_node (parent_node(ft, id)), and is_root (is_root(ft, id)), where 0 denotes no parent.

BasicCompGeometry.BBT.Tree_init — Method
Tree_init(PS; leaf_size=1, compute_diam=true) -> Tree

Build a bounding-box tree over the points of PS (lazily expanded below the root's children).

  • leaf_size: a node becomes a leaf once it holds at most leaf_size points (must be >= 1). Nodes whose points all coincide are always leaves. Nearest-neighbor queries scan every point of a leaf.
  • compute_diam: when false, node diameters are not computed and every node.diam is zero. Such trees must not be used with code that reads diam (e.g. WSPD separation tests or diameter approximation); WSPD and Diameter build their own trees with the default.

WSPD

Well-separated pair decomposition over a BBT tree. init(P, sep) seeds a priority queue of node pairs ordered by an upper bound on their diameter; expand! and expand_bichromatic! refine it into pairs separated by factor sep. Used by approx_diameter and the metric-space routines.

Oriented bounding boxes

MVBB.volume(box) returns the volume of an OBBox. MVBB.rotating_calipers_min_area(hull) takes a 2D convex hull and returns a rectangle description with vertices (four corners) and area fields.

Approximate minimum-volume bounding boxes: oriented boxes (OBBox) built from an approximate diameter direction, plus the exact 2D minimum-area rectangle of a convex polygon by rotating calipers. Start with approx_mvbb.
