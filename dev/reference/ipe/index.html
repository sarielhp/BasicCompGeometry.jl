Ipe canvas and composition

See Vector figures for complete examples, output formats, and external tools. Operations in this reference are exported by IpeDraw. Lower-level drawing and file helpers are on the drawing and export page.

BasicCompGeometry.IpeDraw — Module
IpeDraw

A clean, robust Julia interface for programmatically generating Ipe 7 vector figures. Integrates natively with BasicCompGeometry geometric primitives (Point, Segment, BBox, Polygon) and provides high-level helpers for algorithmic and conceptual diagrams.

BasicCompGeometry.IpeDraw.figure — Method
figure(f, path; keep_source=true, source=:ipe, preview=false, kwargs...)

Generate a figure from geometry. A .pdf target is rendered through Ipe so that geometry and LaTeX labels remain vector content. The editable .ipe source is retained by default. Set preview=true to retain and open the editable source after generation.
