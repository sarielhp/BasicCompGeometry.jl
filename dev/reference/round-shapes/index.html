Circles and ellipses

Spheres, circles, circular arcs, ellipses, and elliptic arcs. Accessors such as center, r_major, r_minor, and rotation_angle require qualification, explicit imports, or Extras.

AccessorResult
r_major(ellipse_or_arc)Major semi-axis radius
r_minor(ellipse_or_arc)Minor semi-axis radius
alpha1(elliptic_arc)Starting ellipse parameter angle
alpha2(elliptic_arc)Ending ellipse parameter angle
end_point(elliptic_arc)Point at the ending angle; paired with start_point

BasicCompGeometry.invert — Method
invert(p::Point{D, T}, ref::Sphere{D, S} = Sphere(zeros(Point{D, Float64}), 1.0))

Invert point p with respect to reference sphere ref centered at O with radius R. The inverse point is P' = O + (R^2 / ||p - O||^2) * (p - O).
