Simplification hierarchies

PntSeqHierarchy builds palettes and hierarchies of simplifications of a point sequence, controlled by a measure of subcurve error. The default measure is the Hausdorff distance to the chord; supply a HierarchyMeasure to control a different error, such as a Frechet distance. The names are not exported: use qualified calls such as BasicCompGeometry.PntSeqHierarchy.hierarchy_init(P).

BasicCompGeometry.PntSeqHierarchy — Module
PntSeqHierarchy

Hierarchical simplification of a point sequence (polygonal curve).

A palette records, for a curve P[1..n], the error of a recursive subdivision of 1:n: a range i:j is split at an interior vertex k chosen by a SplitRule, and err[k] is the largest error of the two sub-ranges (measured by a user supplied function err(P, i:j), the error of replacing P[i:j] by the segment P[i]P[j]). All vertices above an error threshold can then be extracted in time proportional to their number.

A SimplificationHierarchy stores simplifications of the curve at decreasing widths, built from a HierarchyMeasure: the bundle of functions that define the error being controlled. The default measure uses the Hausdorff distance (hausdorff_measure); other measures (for example a Frechet distance) only have to provide their own functions.

Names are not exported; use qualified calls such as BasicCompGeometry.PntSeqHierarchy.palette.

BasicCompGeometry.PntSeqHierarchy.FarthestSplit — Type
FarthestSplit()

Split at the interior vertex farthest from the segment P[i]P[j] (Douglas-Peucker). Ties go to the first such vertex.

BasicCompGeometry.PntSeqHierarchy.HierarchyMeasure — Type
HierarchyMeasure(err, simplify, certify, rule)

The functions defining the error controlled by a hierarchy:

  • err(P, i:j): error of replacing P[i:j] by the segment P[i]P[j].
  • simplify(P, w): a simplification of P with error at most about w, as (Q, indices) where Q[t] == P[indices[t]].
  • certify(P, Q, indices): a computed bound on the error between P and its simplification Q, with Q[t] == P[indices[t]].
  • rule: the SplitRule used for palettes.

BasicCompGeometry.PntSeqHierarchy.MidpointSplit — Type
MidpointSplit()

Split at the middle index (i + j) >> 1. The resulting tree is implicit, so a palette needs only its error vector.

BasicCompGeometry.PntSeqHierarchy.Palette — Type
Palette{T, R}

Subdivision errors of a curve, indexed by vertex: pal[k] is the error recorded where vertex k splits a range (zero for vertices that never split one). It behaves as an AbstractVector{T}.

For MidpointSplit the subdivision tree is implicit and a plain vector of errors can be wrapped in Palette(errs) at no cost. Other rules store the children of every split vertex.

BasicCompGeometry.PntSeqHierarchy.SimplificationHierarchy — Type
SimplificationHierarchy{D, T, M}

Simplifications of the curve P stored from the widest (fewest vertices) to the narrowest: polys[i] has error widths[i], and widths is non-increasing. plt is the palette of P and len its length. Access is guarded by lock.

BasicCompGeometry.PntSeqHierarchy.SplitRule — Type
SplitRule

Supertype of the rules choosing the vertex at which a range i:j of a curve is subdivided. split_vertex(rule, P, i, j) returns a vertex k; a range with no valid interior vertex (!(i < k < j)) is a leaf.

BasicCompGeometry.PntSeqHierarchy.hausdorff_measure — Method
hausdorff_measure()

The default HierarchyMeasure: subcurve error is the Hausdorff distance to its chord, simplification is hausdorff_simplify, and palettes split at the vertex farthest from the chord.

BasicCompGeometry.PntSeqHierarchy.hierarchy_approx — Method
hierarchy_approx(h, w, n_max = 25, resolution = 4.0)

An approximation of the curve with error at most about w, returned as (Q, width). If a stored level has width within a factor resolution below w, the finest stored level with fewer than n_max vertices is returned (resolution is used only to look levels up). Otherwise a level is computed, stored in h, and returned: the new level is built from a coarser level, or from the palette, of width about w / 4. This factor is fixed.

The stored levels are read under h.lock, so concurrent calls and pushes are safe.

BasicCompGeometry.PntSeqHierarchy.palette — Method
palette(P, err; rule = MidpointSplit())

Build the Palette of the curve P. err(P, i:j) is the error of replacing P[i:j] by the segment P[i]P[j], for example hausdorff_dist_subseg. The coordinates must be floating point. With FarthestSplit the construction recurses once per split and costs O(n) per split, so a badly skewed subdivision (for example a spiral with a very large number of vertices) takes quadratic time and deep recursion; MidpointSplit has logarithmic depth.

source
BasicCompGeometry.PntSeqHierarchy.palette_extract — Method
palette_extract(P, pal, w)

Extract an approximation of P from its palette (running time proportional to the output size). Returns (Q, indices, w_out): Q is the simplified curve, indices are the vertices of P it keeps, and w_out bounds the error of the subranges that were not subdivided further, which is below w whenever w exceeds the largest error in the palette. pal may be a Palette or a plain error vector, which is taken to use MidpointSplit. A curve of at most four vertices is returned whole, with w_out = 0, whatever w is.

source
BasicCompGeometry.PntSeqHierarchy.palette_level — Method
palette_level(P, pal, level)

Extract the approximation of P made of the first level levels of the subdivision tree (the first and last vertices are always kept). Returns (Q, indices). For a one-vertex curve the vertex appears twice.
