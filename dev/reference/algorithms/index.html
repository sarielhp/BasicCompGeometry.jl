Hull and diameter algorithms

See Algorithms and spatial structures for examples and Kernels and numerical scope for arithmetic limits. Feature submodule operations use qualified names.

2D hull and diameter queries

CallResult
convex_hull(points; kernel=FloatingKernel())Counterclockwise PntSeq hull, using monotone chain in O(n log n) time
exact_diameter(points)Maximum pair distance from an O(n²) scan
approx_diameter(points, ε)WSPD-based (1 + ε) diameter approximation
exact_diameter_subspace(points, dir)Diameter after orthogonal projection to the complement of unit dir
approx_diameter_subspace(points, ε, dir)Approximate projected diameter

The hull accepts a vector of 2D points or an AbsPntSeq. Diameter operations accept an AbsPntSeq. Request ExactKernel() for exact hull decisions; the diameter routines use ordinary distance arithmetic.

3D convex hull

BasicCompGeometry.ConvexHull3D — Module
ConvexHull3D

This module implements the Randomized Incremental Algorithm for computing the convex hull of a set of points in 3D.

The algorithm has an expected running time of O(n log n).

source
BasicCompGeometry.ConvexHull3D.convex_hull_3d — Method
convex_hull_3d(points)

Computes the 3D convex hull of a set of points. Returns a pair (vertices, faces) where vertices is a vector of indices into the original point set, and faces is a vector of triples of indices into the vertices vector.

source
BasicCompGeometry.ConvexHull3D.verify_convex_hull_3d — Method
verify_convex_hull_3d(pnts, verts_idx, faces)

Verifies the geometric and topological properties of a 3D convex hull. Checks:

  1. Every face is a triangle.
  2. Convexity: All points lie on one side of each face's plane.
  3. Manifold: Every edge is shared by exactly two faces with opposite orientations.
  4. Correctness: Every face has 3 edges.

Returns (success::Bool, message::String).

Longest convex subset

BasicCompGeometry.LongestConvexSubset — Module
LongestConvexSubset

This module implements an algorithm to find the largest convex subset of a given set of points. The algorithm uses dynamic programming (DP) to compute the longest convex chain between pairs of points and then combines upper and lower chains to form the longest convex polygon.

The running time of the algorithm is O(n^3 log n).
